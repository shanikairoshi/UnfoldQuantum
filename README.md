# UnfoldQuantum — v1.0
Provisional brand: From Intuition to Innovation.

## Open offline
Extract ZIP and keep all files together. Double click index.html. No dependencies, accounts or internet required for lesson content. External further-reading link needs internet. Progress and reflection are stored locally where browser permits; no server collects data.

## Publish publicly
1. Create a public GitHub repository (e.g. beyond-the-equation).
2. Upload index.html, style.css, lessons.js, app.js and README.md to the repository root.
3. In Settings → Pages select Deploy from a branch, main, / (root), then Save.
4. Open the published URL shown by GitHub and test on mobile and desktop. Add this URL to YouTube and LinkedIn profiles.
5. Edit the follow section in index.html to include your actual channel and newsletter links; no placeholder links are presented as active.

## Extend the project
lessons.js contains the seven learning stages. app.js handles the compass, progress, and navigation. style.css contains the visual identity. index.html contains the landing page and lesson shell. For additional lessons, create a new page using the same style and use a unique localStorage key. Later refactor lesson-specific experiments into modules and add an index of lessons. The next two lessons are roadmap items only.

## Editorial checklist
Every lesson: familiar story, prediction, visual intuition, derive equation, interactive test, code, research limitation, independent creation challenge. Include precise definitions and explain limits of analogies. Verify numerical examples and references before publishing. Review accessibility with real learners. Decide licensing and check institutional IP obligations before open-source release. The author and project name are provisional; no trademark search performed. No claims of demonstrated quantum advantage.

## Launch strategy
Publish a short video asking why 350 and 10 average to 180. Link to the free lesson. Publish a companion article with the derivation and a challenge on LinkedIn. Invite readers to share a new circular-data problem. Add actual follow links once accounts are ready. Track repeat visits and lesson feedback only after selecting a privacy-respecting strategy; no tracking is currently installed.
